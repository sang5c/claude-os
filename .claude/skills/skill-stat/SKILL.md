# skill-stat

PreToolUse/Stop 훅이 쌓은 스킬 사용 로그를 집계해 표로 출력한다.

## 사용법

집계 스크립트를 실행하고, 출력된 표를 그대로 사용자에게 보여준다.

```bash
python3 .claude/skills/skill-stat/stat.py
```

- 스크립트는 자기 위치 기준으로 프로젝트 루트를 찾으므로 별도 인자가 필요 없다.
- 데이터 소스: `.claude/stats/skill-usage.jsonl` (훅이 기록, git 미추적).
- 표 컬럼: **스킬 / 호출(횟수) / 총 소요 / 평균 소요 / 마지막 사용**, 호출 횟수 내림차순.
- 데이터가 없으면 스크립트가 "아직 기록된 데이터가 없습니다"를 안내하므로 그대로 전달한다.

## 동작 메모

- 통계 기록은 순수 훅+스크립트(`.claude/hooks/skill-stat-start.sh`, `skill-stat-stop.sh`)가 담당한다. 이 스킬은 조회 전용이다.
- 시간 정의: 스킬 호출 시점 ~ 턴 종료(Stop). 한 턴에 여러 스킬을 쓰면 다음 스킬 호출 시점까지로 끊어 귀속한다.
