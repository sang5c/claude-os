# finance-review

재무 OS의 워크플로우를 순서대로 실행하는 **시작점**이다. 개별 스킬·에이전트를 묶어 한 번에 돌린다. 직접 계산을 새로 하지 말고 각 단계 결과를 모아 종합한다.

## Workflow

1. **자산 점검** — `asset-check` 스킬을 실행한다. (현재 vs 목표 배분)

2. **월 적립 플랜 — 필요 여부 판단 후 실행**
   - `finance/contributions.md`를 확인한다.
   - 유효한 적립 규칙이 1개 이상 있으면 → `monthly-plan` 스킬을 실행한다. (이번 달 적립액 계산, `market-price` 에이전트 사용)
   - 규칙이 없거나 비어 있으면 → 실행하지 않고 "적립 규칙이 없어 월 적립 플랜은 생략"이라고 알린다.
   - 1단계 점검상 이미 목표 배분에 도달해 추가 적립이 불필요해 보이면, 실행하되 그 사실을 한 줄로 짚는다.

3. **연간 사이클 단계 판단** — 오늘 날짜로 해당 단계를 정한다.
   - 매월: 자산 기록·점검 (1·2단계가 이에 해당)
   - 분기 말(3·6·9·12월): 포트폴리오·자산배분 리밸런싱 검토 → *미구현, 예정*
   - 12월: 절세 막바지 점검 → *미구현, 예정*
   - 1~2월: 연말정산 + 올해 목표 설정 → *미구현, 예정*

4. **종합 — "이번에 할 일"**
   - 위 결과를 모아 오늘 기준 액션 리스트를 만든다. (목표 격차를 좁히는 적립 방향, 이번 달 적립액, 시기상 해야 할/예정 단계 등)
   - 아직 미구현인 단계는 "다음 보강 거리"로 한 줄 남긴다.

## 주의

- 이 스킬은 하위 스킬(`asset-check`, `monthly-plan`)과 에이전트(`market-price`)를 호출하는 **진입점**이다. 각 단계는 해당 스킬에 맡기고 결과만 종합한다.
- 데이터 파일(`finance/`)은 git 미추적. 커밋·외부 반출 금지.
