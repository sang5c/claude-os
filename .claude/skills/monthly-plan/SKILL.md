# monthly-plan

거래일 단위 적립 규칙을 읽어, 이번 달 종목별로 얼마를 넣게 되는지 원화로 계산해 보여준다. 재무 OS의 "꾸준히 넣어 증식" 단계를 담당한다.

## Workflow

1. **규칙 읽기** — `finance/contributions.md`를 읽는다. 없으면 사용자에게 알리고 형식대로 만들지 제안한다.
   - 각 종목이 **정량(주수)**인지 **정액(원)**인지 구분한다.

2. **현재가 확보** — 정량 종목(예: KODEX 2주)은 원화 금액 환산에 현재가가 필요하다.
   - `market-price` 에이전트에 해당 종목을 넘겨 현재가를 받는다. (정액 종목은 가격 불필요)

3. **거래일수 추정** — 이번 달 거래일을 추정한다(주말·공휴일 제외, 보통 약 20~22일). 추정임을 명시한다.

4. **계산** — 종목별 월 적립액을 구한다.
   - 정량: `현재가 × 주수 × 거래일수`
   - 정액: `금액 × 거래일수`
   - 종목별 합계와 **월 총 적립액**을 표로 제시한다.

5. **코멘트(선택)** — 월 적립이 목표 자산배분(`docs/finance-policy.md`)에 어떻게 기여하는지 한 줄. 단정적 조언이 아니라 숫자에 근거한 관찰로.

## 주의

- 현재가는 조회 시점 기준이라 실제 체결가·거래일수에 따라 달라진다. 계산은 추정치임을 밝힌다.
- `finance/contributions.md`는 git 미추적(민감 데이터). 내용을 커밋하거나 외부로 내보내지 않는다.
- 적립 규칙 변경은 사용자가 파일을 고치거나 동의받고 수정한다.
