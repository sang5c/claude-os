# asset-check

`finance/assets.md`에 기록된 자산 현황을 읽어 요약·점검한다. 재무 OS의 **성장 지향** 철학(지금은 리스크를 감수하더라도 높은 수익률 추구)을 기준으로 본다.

## Workflow

1. **데이터 읽기**
   - `finance/assets.md`를 읽고, 맨 위(가장 최신) 스냅샷을 기준으로 한다. 없으면 사용자에게 알리고 형식대로 만들지 제안한다.
   - `docs/finance-policy.md`가 있으면 읽어 **목표 자산배분**을 확보한다. 없으면 목표 비교는 건너뛴다.

2. **요약**
   - 항목 금액을 합쳐 **순자산 합계**를 낸다.
   - 항목별 **현재 비율(%)**을 표로 보여준다.

3. **목표 대비 격차** (정책이 있을 때) — 자산군별로 현재 비율과 목표 비율을 나란히 놓고 **격차(±%p)**를 표시한다.
   - assets.md 항목을 정책의 자산군에 매핑한다. 예: 미국주식 + 국내주식 → 주식.
   - 정책에 없는 자산군(예: 기타)은 별도로 표시한다.

4. **관점 코멘트** — 성장 지향 철학과 목표 대비 격차에 비춰 한·두 줄.
   - 격차가 큰 자산군을 짚는다. 예: "현금이 목표보다 +10%p — 비상금 제외분을 주식으로 옮기는 것 고려".
   - 단정적 투자 조언이 아니라 **숫자에 근거한 관찰**로 제시한다.

5. **후속 제안(선택)** — 원하면 이번 달 스냅샷 추가, 리밸런싱 논의 등으로 이어간다. 파일 수정은 동의받고 한다.

## 데이터 형식

```markdown
# 자산 현황 (단위: 원)

## 2026-05 (기준일 2026-05-28)
- 미국주식: 0
- 국내주식: 0
- 연금저축/IRP: 0
- 현금/예금: 0
- 기타: 0
```

새 스냅샷은 맨 위에 추가한다(최신이 위). 항목은 자유롭게 바꿔도 된다.

## 주의

- `finance/assets.md`는 git 미추적(민감 데이터). 내용을 커밋하거나 외부로 내보내지 않는다.
- 시장가·세법 같은 외부 조사는 v1 범위가 아니다(로컬 데이터만 읽음). 필요해지면 별도 리서치로 분리한다.
