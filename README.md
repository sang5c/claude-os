# claude-os — 클로드 OS 실습 저장소

"클로드 OS"를 직접 만들어보며 AI와의 협업 방식을 배우는 실습 공간.
작은 쓸모 있는 단위를 먼저 만들고 돌려본 뒤, 부족한 부분을 다음 단계에서 보강한다.

## 구조

| 경로 | 역할 |
|---|---|
| `CLAUDE.md` | 프로젝트 전역 규칙 (항상 주입되는 컨텍스트) |
| `.claude/skills/` | 스킬 (필요할 때 lazy 로딩) |
| `.claude/agents/` | 서브에이전트 |
| `.claude/hooks/` | 훅 (이벤트 시 자동 실행) |
| `finance/` | 재무 데이터 (실제 숫자, **git 미추적**) |
| `docs/` | 비민감 도메인 문서 (투자 원칙·목표 등) |
| `notes/` | 주차별 학습 노트·회고 |
